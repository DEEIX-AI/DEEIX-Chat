## 规则

1. **表里没有的端就是不支持。** 不要因为"顺手能加上"就在移动端加 Admin 这类功能；范围一旦模糊，两个端就会各自长出不同的实现。
2. **新增一行时必须回答两个问题：** 逻辑是否需要 `packages/core` 新增抽象？UI 是否需要在两端各写一遍？如果答案是"逻辑各写一遍"，那是架构违规。
3. **◐ 必须写清楚限制。** 只写"部分支持"等于没写。
4. **桌面端不新增业务功能行。** 桌面 = Web + 系统集成能力；只要出现"桌面端能做但 Web 端不能做"的业务功能，就说明抽象放错了层。
